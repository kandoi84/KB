# Session templates

1. Save original audio references, transcripts, or supplied notes in the relevant topic's `raw/` folder and register their origin and limits. A transcript is not an audio recording.
2. Copy [voice-session.md](voice-session.md) to `topics/voice-practice/notes/YYYY-MM-DD-name.md`, or [codex-session.md](codex-session.md) to `topics/codex-work/notes/YYYY-MM-DD-name.md`.
3. Optionally copy [combined-review.md](combined-review.md) into the Codex notes folder for a short wrap-up. Coding remains the main focus.
4. Replace every placeholder, repair the source and session links for the destination, and use the same session ID across linked entries. If information is absent, write `not recorded` or `not assessed`.
5. Use [trends.md](trends.md) in a topic's analysis folder when comparable evidence is available; update topic navigation and run the checker.

Templates use plain text placeholders for paths because their final source files do not exist yet. Turn source/session placeholders into relative Markdown links when copying.
